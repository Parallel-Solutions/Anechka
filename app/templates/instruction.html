Bitrix24 Export — выгрузка телефонов в Tomoru и обработка результатов прозвона обратно в CRM.

1. Краткая инструкция для пользователя

Сценарий A — Выгрузка телефонов в Tomoru
  1. Убедитесь, что в Настройках указан вебхук Bitrix24 и выполнен CRM Импорт.
  2. На главной странице выберите воронку, при необходимости — стадии, регион и период.
  3. Проверьте превью сделок и контактов; при необходимости снимите или поставьте галочки «Выгрузка».
  4. Нажмите «Запустить выгрузку» — откроется Tomoru, CSV скачается автоматически. Загрузите файл в Tomoru.
Сценарий B — Обработка результатов прозвона
  1. Откройте Результаты прозвона и загрузите файл XLSX или CSV.
  2. Дождитесь завершения обработки и нажмите «Открыть» у нужного импорта.
  3. Пройдите вкладку «Ручная проверка» — решите спорные строки в модальном окне.
  4. Нажмите «Отправить в Битрикс и выгрузить автобзвон».
  5. При необходимости выгрузите отдельные категории (ручной или автоматический обзвон) через кнопки на соответствующих вкладках.

2. Подробное описание — как работает сервис

Сервис связывает локальную копию CRM Bitrix24 с двумя рабочими процессами: выгрузкой телефонов в автодозвон Tomoru и обратной загрузкой результатов прозвона в Bitrix24.
2.1 Главная страница — Выгрузка для Tomoru

Страница доступна по адресам / и /tomoru-export. Здесь формируется CSV-файл с телефонами для загрузки в автодозвон Tomoru.

Статус в шапке страницы

  • Bitrix24: подключено — вебхук настроен и отвечает.
  • Импорт CRM — дата последней успешной синхронизации данных из Bitrix24.
  • Если данные устарели, появится предупреждение: перед выгрузкой запустите инкрементальный импорт в Настройки → CRM Импорт.

Фильтры выгрузки

  • Воронка — обязательна для запуска выгрузки.
  • Стадии — можно выбрать несколько; пустой выбор означает «любая стадия».
  • Регион — мультивыбор по справочнику регионов.
  • Период создания — даты в формате ГГГГ-ММ-ДД (поля «С» и «По»).

Превью «Сделки и контакты»

Таблица появляется после выбора хотя бы одного фильтра (воронка, стадия, регион или период).

  • Список сделок со ссылками на карточки в Bitrix24.
  • Для каждой сделки — вложенные контакты и телефон компании.
  • Колонка «Уверенность ЛПР» — AI-классификация лиц, принимающих решение (зелёный ≥ 80%, жёлтый ≥ 50%, красный ниже).
  • Режимы просмотра: «Все» или «Только неуверенные» с настраиваемым порогом (%).
  • Чекбоксы «Выгрузка» — выбор контактов и телефона компании для CSV; выбор сохраняется автоматически.
  • Пагинация по 50 сделок на страницу.
  • Фильтры сохраняются в URL — ссылку можно отправить коллеге.

Кнопка «Запустить выгрузку»

  1. Открывает приложение Tomoru в новой вкладке.
  2. Скачивает CSV с телефонами по текущим фильтрам и выбранным контактам.
2.2 Страница загрузки — Результаты прозвона

Здесь загружается файл с результатами прозвона для подготовки данных к отправке в Bitrix24.

Загрузка файла

  • Форматы: XLSX или CSV, до 50 МБ.
  • Перетащите файл в зону загрузки или нажмите для выбора — обработка начнётся автоматически.

Особые случаи

  • Excel с несколькими листами — появится выбор нужного листа.
  • Нестандартный формат — потребуется ручное сопоставление колонок (телефон, транскрипт и др.).
  • CSV формата Tomoru — распознаётся автоматически, маппинг не нужен.

Таблица «Последние импорты»

Показывает до 15 последних загрузок: ID, имя файла, статус, число строк, дата. Кнопка «Открыть» ведёт на страницу обработки импорта.

2.3 Страница обработки импорта — /call-results/imports/{id}

Открывается после загрузки файла или из списка последних импортов.

Автоматический pipeline (фоновый worker)

  1. Парсинг файла — чтение строк и нормализация телефонов.
  2. Сопоставление — поиск сделок CRM по номеру телефона.
  3. Классификация — определение результата звонка (правила + LLM).
  4. Планирование — подготовка операций для Bitrix24 (комментарии, дела, контакты, повторные звонки).

Модальное окно строки

При клике на строку открывается карточка с транскриптом звонка, сопоставленной сделкой и запланированными операциями. Для вкладки «Ручная проверка» доступны действия:

  • Добавить комментарий в таймлайн сделки
  • Создать CRM-дело
  • Создать новый контакт
  • Найти другой контакт (перевод в автобзвон)

Кнопки управления

  • Отправить в Битрикс и выгрузить автобзвон — массовая отправка подготовленных операций и скачивание CSV для повторного автодозвона.
  • Запустить заново — повторная обработка файла (недоступна во время обработки).
  • Удалить импорт — удаление импорта и всех связанных данных.

Статусы импорта

Страница обновляется автоматически каждые 2–3 секунды во время обработки:

processing → ready → executing → completed / failed

2.4 Настройки — /settings
  • URL вебхука Bitrix24 — подключение к порталу CRM.
  • API-ключ OpenAI / LLM — для классификации результатов прозвона и определения ЛПР.
  • История — журнал прошлых выгрузок.
  • CRM Импорт — синхронизация сделок, контактов и справочников из Bitrix24. От актуальности этих данных зависят обе основные страницы сервиса.
